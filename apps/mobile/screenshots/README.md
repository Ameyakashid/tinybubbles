# ⚠️ These images still show upstream Mindwtr branding

Every screenshot and marketing image in this directory was produced by the upstream
[Mindwtr](https://github.com/dongdongbh/Mindwtr) project. Several of them contain the
**Mindwtr wordmark and logo** rendered into the image itself, which no amount of
find-and-replace in the source can change.

**They must be regenerated before Tiny Bubbles submits to any app store or listing.**
Publishing them as-is would advertise a different product's brand as ours, and would use
upstream's marketing artwork without a licence to their trademark — the AGPL covers the
code, not the name or logo.

They are retained for now because they document what the corresponding screens look like
and are useful as a shot list when producing replacements. The release workflows that would
upload them are disabled by default (see the `ENABLE_RELEASE_WORKFLOWS` guard in
`.github/workflows/`), so they cannot be published by accident.
